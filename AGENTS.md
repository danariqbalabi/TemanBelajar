# alur kerja

- Kerjakan perubahan baru di branch terpisah; jangan langsung di `main`.
- Gunakan prefix sesuai pekerjaan, misalnya `feat/`, `fix/`, `docs/`, atau `chore/`.
- Nama branch setelah prefix dan judul commit memakai bahasa Indonesia lowercase yang santai dan jelas.
- Contoh: `feat/beresin-daftar-dan-masuk-akun` dan `feat: bikin daftar dan masuk akun jalan bener`.
- Push ke branch pekerjaan. Merge atau push ke `main` hanya setelah diminta pengguna.
- Ikuti juga instruksi tambahan dalam `AGENTS.md` di subfolder terkait.
