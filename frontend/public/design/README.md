# aset desain asli

- `logo.png` dan `mimo.png` berasal dari arsip desain Stitch yang diberikan pengguna: `stitch_temanbelajar_design_system (3).zip`.
- `symbols.woff2` adalah font Material Symbols Outlined dari Google Fonts. Lisensinya terdapat pada `LICENSE-symbols.txt`.
- Struktur landing, halaman masuk, onboarding, serta dashboard dipindahkan dari HTML screen 01–07, dengan screen 07 memakai arsip revisi `(4)`.
- Katalog, unggahan, proses, ringkasan, dan pemilih mode mengikuti HTML screen 08–12. Ilustrasi `subject-science.png` dan `subject-math.png` disimpan lokal dari URL aset yang dirujuk HTML screen 08.
- Script contoh dari ekspor tidak dijalankan. Kontrol memakai state React dan API aplikasi. Angka progres, pilihan pengguna, dan alasan rekomendasi berasal dari data aplikasi; teks contoh diberi konteks pratinjau.
