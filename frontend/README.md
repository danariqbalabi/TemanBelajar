# frontend temanbelajar

Next.js App Router + TypeScript. Jalankan dari folder ini:

```powershell
npm ci
npm run dev
```

Backend lokal berada di `http://localhost:8000`. Salin `.env.example` ke `.env.local` untuk mengubah alamat API. Jangan masukkan service role, database URL, atau key Gemini ke frontend.

Tahap pertama menyediakan dashboard yang mengikuti screen 07, navigasi responsif, materi demo dari endpoint publik backend, pembaca per konsep dengan sumber, transkrip dan baca nyaring browser, serta preferensi perangkat. Data target dan jadwal pada dashboard diberi label sebagai rencana contoh. Progres personal dan penyimpanan jadwal menunggu integrasi akun.

```powershell
npm run lint
npm run build
```
